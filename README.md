# Open Here in CMD - Registry Script

This repository contains a Windows Registry (`.reg`) script that adds an "Open Here in CMD" option to the right-click context menu when inside a folder.

## Features
- Adds an option to open the Command Prompt in the current folder.
- Works on Windows 10 and Windows 11.
- Lightweight and easy to install.

## Installation
1. Download the `OpenCmdHere.reg` file from this repository.
2. Double-click the file to run it.
3. Click "Yes" to confirm adding the registry changes.
4. Right-click inside any folder and select **"Open Here in CMD"**.
